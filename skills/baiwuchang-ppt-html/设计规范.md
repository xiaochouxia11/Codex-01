# 百无常 · PPT 设计规范（唯一规范）

> 一句话：**纯 HTML/CSS、严格三色、统一密集圆点、思源黑体（标题超粗·正文细）、4 套同源配色、左下角放灰色 logo。**
> 配套：`html参考/`（4 套可运行模板）、`示例png/`（预览）。

---

## 1. 铁律（每页都必须满足）
1. 纯 HTML/CSS，**零图片、零截图**；图形（圆点、渐变、雷达盘、卡片）一律 CSS / 内联 SVG 生成；文字必须可选中。
2. **严格配色**：白底 `#ffffff` + 黑字 `#000000` + **一个**强调色。其余"灰"只能是黑/白透明度，**禁止任何其它色相**（渐变本身除外）。
3. **统一圆点背景**：每页同一套极细 (0.9px)、极密 (12px) 小圆点，不得关闭；黑块上改用白点。
4. **字体统一思源黑体（Noto Sans SC）**：标题 `font-weight:900`，正文 `font-weight:300`。
5. **画布固定 1672×941（16:9）**，靠 `--deck-scale` 自适应缩放。
6. **左下角放灰色 logo**（`灰色logo2.png`，替换原来的 DESIGN 文字）。
7. 强调色克制（约 5%–25%），**文字始终纯黑**，每屏高亮 ≤ 1 项。

## 2. 设计令牌（`:root`）
```css
--paper:#ffffff; --ink:#000000;
--lime:#39ff14;  --lime-2:#23e000;        /* 强调色：换主题只改这一对 */
--muted:rgba(0,0,0,.5); --line:rgba(0,0,0,.12); --soft:rgba(0,0,0,.06);
--dot:rgba(0,0,0,.07);  --dot-light:rgba(255,255,255,.16);
--font:"Noto Sans SC","Source Han Sans SC","PingFang SC","Microsoft YaHei",sans-serif;
--slide-w:1672px; --slide-h:941px;
```
圆点背景：`background:var(--paper); background-image:radial-gradient(var(--dot) .9px,transparent 1px); background-size:12px 12px;`

## 3. 字重阶梯（粗细结合）
| 角色 | 字重 | 字号 |
|---|---|---|
| 大标题 / 大数字 | **900** | 72–150px |
| 子标题 / 卡片标题 | 700 | 22–34px |
| 小标签（大写 + 强调色下划线 `.kicker`） | 700 | 16px |
| 引导段 `.lead` / 正文 `.body-text` `p` | 300 | 17–24px |
| 页脚 | 300 | 13px |
口诀：**标题数字要狠（900），叙述文字要轻（300）**。

## 4. 页面骨架
每页：`<section class="slide" data-page="序/总" data-code="代号"><div class="content 版式类">…</div></section>`。
页眉 / 页脚 / 翻页由脚本**自动注入**：
- 页眉：圆点 logo + 品牌 + 元信息 + 页码。
- 页脚：**左 = 灰色 logo 图片**（`<img src="./灰色logo2.png" style="height:24px">`），右 = `data-code`。
- 交互：← → / 空格 / 滚轮 / 触摸 / 圆点；支持 `…template.html#N` 深链到第 N 页（方便逐页截图）。

## 5. 六种版式（复制即用）
- `.cover` 封面：`.kicker` + 超粗 `h1` + `.lead` + `.tag`，右侧 `.cover-mark`（装饰）。
- `.divider` 章节分隔：巨大 `.divider-num` + 标题 + `.divider-list`。
- `.content-std` 大标题+正文：左 `.content-main`（`h1`+多段 `.body-text`），右 `.content-aside`（黑底高亮指标）。
- `.cards-3` 三栏要点：3 张 `.card`，重点卡加 `is-active`（变强调色）。
- `.data-grid` 关键数据：4 个 `.stat`（超粗数字 + 进度条），重点加 `is-active`。
- `.closing` 结束页：`.kicker` + 巨大 `h1`（`<em>` 部分变强调色描边）+ `.closing-contact`。

> 精确 HTML 片段直接看 `html参考/极简/template.html`，改字即可。

## 6. 配色主题机制（4 套同源）
**复用 + 单点改色 + 叠加装饰**：
1. 主题 css 第一行 `@import url("./base.css")`，继承全部版式。
2. 只重声明 `:root{ --lime:主题色; --lime-2:辅色 }` → 所有点缀一处改、全局换。
3. 叠加 `.slide::before`（柔和渐变光）+ `.slide::after`（极细颗粒，内联 SVG）。
4. 封面 `.cover-mark` 重绘为柔和渐变光团。

| 主题 | `--lime` | `--lime-2` |
|---|---|---|
| 极简 minimal | `#39ff14` | `#23e000` |
| 暖橙 warm-orange | `#ff6a1a` | `#ff3d6e` |
| 蓝 blue | `#1f6bff` | `#7c3aed` |
| 彩色 rainbow | `#7c3aed` | `#ff4d8d` |

### ⚠️ 渐变黄金法则（最重要）
渐变必须**柔和、自然过渡、无实体边界**——像光晕，不是实体球。
- **禁止**：实色铺到边缘、`border-radius` 实体轮廓、`conic-gradient` 实色、`mask` 实心核心（如 `…#000 56%`）。
- **应当**：多层「提前淡出到透明」的径向光（透明停在 **70%~80%**）+ `filter: blur(30~40px)` 化开边缘。
示例（暖橙封面，蓝/彩色见对应 css）：
```css
.cover-mark{ width:540px; height:520px; overflow:visible; box-shadow:none; border-radius:0;
  background:
    radial-gradient(42% 44% at 44% 38%, rgba(255,178,76,.92), transparent 76%),
    radial-gradient(38% 40% at 63% 58%, rgba(255,74,112,.84), transparent 78%),
    radial-gradient(32% 34% at 32% 66%, rgba(255,140,48,.74), transparent 74%),
    radial-gradient(30% 30% at 70% 30%, rgba(255,208,98,.66), transparent 72%);
  filter:blur(32px) saturate(1.04); }
.cover-mark::before{ content:""; position:absolute; width:320px; height:320px; right:-30px; bottom:-36px; z-index:-1;
  background:radial-gradient(46% 46% at 50% 50%, rgba(255,110,64,.7), transparent 80%); filter:blur(40px); opacity:.85; }
.cover-mark::after{ content:none; }
```

## 7. 字体加载
```html
<link href="https://fonts.googleapis.com/css2?family=Noto+Sans+SC:wght@200;300;400;500;700;900&display=swap" rel="stylesheet" />
```
离线回退本机思源黑体 / 苹方 / 微软雅黑。

## 8. 两种交付物（同一份内容，两种形态）
1. **HTML 形式 PPT**：直接用 `html参考/<主题>` 改字而成，浏览器打开播放，视觉 100% 还原本规范。
2. **可编辑 PPTX**：用 `python-pptx` 生成原生 PowerPoint，**文字可改、图片可换**；
   颜色/字体/版式遵循本规范（白底、黑超粗标题、细正文、强调色），渐变以 PowerPoint 渐变填充近似。
   左下角 logo、封面图片均为**可右键替换的图片**。

## 9. 自检清单
- [ ] 无 `<img>` 外部图片（logo 除外）；文字可选中。
- [ ] 只有白/黑/单一强调色（+该主题渐变）；灰=黑白透明度。
- [ ] 圆点背景每页一致；标题 900 / 正文 300，思源黑体。
- [ ] 左下角是灰色 logo；`data-page` 分母=总页数。
- [ ] 渐变柔和无边界（封面光团 + 页面光）。
- [ ] 浏览器翻页正常；PPTX 文字可改、图片可换。
