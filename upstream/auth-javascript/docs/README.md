# Sign in with ChatGPT integration guides

Use [Getting started](getting-started.md) to install the SDK. The guide explains
how to connect it to your authentication system.

## Add sign-in to your app

- [React components](../packages/react/README.md): provider setup, sign-in buttons,
  profile pictures, and hooks for React 18 and 19.
- [DOM utilities](../packages/core/README.md): mount a button in plain JavaScript
  or integrate with another UI framework.
- [Next.js/Auth.js example](../examples/authjs/README.md): connect an OAuth client,
  verify identity server-side, and display an application session.
- [Browser examples](../examples/browser/README.md): try DOM and React with local
  simulated sign-in, without credentials.
- [Create an independent Auth.js app](../examples/authjs/README.md#create-an-independent-app).

## Customize and deploy

- [API reference](api.md): configuration, adapters, clients, profiles, and presentation.
- [Button branding](branding.md): SDK presets, permitted layout styles, and accessibility exceptions.
- [State and recovery](recovery.md): progress, errors, retries, and browser restoration.
- [Content Security Policy](csp.md): external CSS, Trusted Types, and profile image policy.
- [Localization](localization.md): language selection and right-to-left layout.
- [Accessibility](accessibility.md): accessible labels, focus, keyboard use, and errors.
- [HTTPS setup](authjs-https.md): callback URLs, reverse proxies, and secure cookies.
- [UI playground](playground.md): inspect appearance, layout, and interaction options.
