# Use selected migration skills

Use this guidance when intent selects extra skills for an assignment, including
early stages and delegated work. Selection and installation remain owned by
[initialize](../../initialize/references/migration-skills.md); this reference governs use.

## Load and delegate

Read intent for selected instructions and applicability, and the
[execution details](records/artifacts.md#execution-environment-details) for pinned identities,
setup choices, and availability evidence.
`None`, `Open`, absent selections, and skipped entries activate no extra skills.

Load only instructions relevant to the assignment at the recorded immutable
identity. Follow [Workflow access](../../preflight/references/checks/workflow-access.md)
for runtime verification; setup alone does not establish availability.
For reporting or synthesis from saved evidence, read applicable instructions
without installing skills or running capability checks.

Give workers the applicable references, immutable identities, scope, integration
notes below, and [continuation context](records/presentation.md#continuation-context),
including for use without installation. Workers read the instructions and return
what they applied or could not load to the coordinator; tool availability grants
no record-writing or approval authority. Missing or mismatched instructions pause
only affected work and return to initialize. Do not install during execution or
claim unread guidance was used.

## Integration notes

CodeMod's accepted scope, repository guidance, stage ownership, human approvals,
and required evidence take precedence over imported skill preferences. Reuse
equivalent CodeMod test, review, and verification procedures for imported
prerequisites; resolve unmet prerequisites explicitly. Selection does not activate
dependencies, hooks, a whole skill suite, or another orchestrator.
